# Product imagery

Generated/edited with the built-in image generation tool. Original PNG masters are kept in `docs/image-sources/`. The storefront uses losslessly encoded WebP files in `public/products/`: every visible pixel and every alpha value matches its master. Only invisible RGB values at alpha zero are discarded by the encoder. Product photographs are illustrative references; the studio confirms each school's requirements.

School style reference: https://royalcollege.lk/general-rules/ (junior navy shorts and senior white full-length trousers; details vary by school). No badge or tie is assumed.
